InPage conversion guide & FAQ

How do I convert old InPage text to Unicode?

Open your document in InPage, copy the text and paste it into the source editor. Select InPage → Unicode. If prefix bytes were lost, try the unprefixed option only on legacy text. Review the result, then copy into Word, websites or social media.

How do I convert Unicode to older InPage?

Select Unicode → legacy InPage and copy the encoded output. Test a short sample in your particular InPage version first. The original site mapping is available for compatibility but contains different character assignments.

Can I open native INP documents?

Not directly. Text exports are supported; proprietary binary INP documents require a document parser or the original InPage application. Formatting and page layouts are not preserved.

Is my text private?

All conversion and graphics processing occurs in this page. No text is sent to a server or saved in browser storage. Clipboard access requires browser permission. Your hosting provider may separately log ordinary page requests.

Which versions are supported?

Documented legacy byte-pair mapping targets older v1/v2 text, and modern Unicode is supported. Specific InPage 2000, 2009, 2012 and 3.x clipboard behavior must be tested on Windows. No universal compatibility or accuracy guarantee is made.

Technical reference and diagnostic tests

Community InPage character mapping reference. Unknown characters are preserved and reported rather than silently discarded.
