# Urdu Unicode & InPage Converter + Publishing Toolkit 🇵🇰

A fast, 100% free, browser-based **InPage ↔ Unicode Urdu Converter** and **Urdu Publishing Toolkit** designed for graphic designers, journalists, students, book publishers, and YouTube/social media creators.

🔗 **Live Website:** [https://urdu-converter.pages.dev/](https://urdu-converter.pages.dev/)

---

## ✨ Key Features

- **Two-Way InPage ↔ Unicode Conversion:** Convert proprietary InPage Urdu text into standard UTF-8 Unicode and convert Unicode Urdu back into InPage-compatible clipboard format (`Windows-1252` + `\u0004` byte pairing) for **InPage 2000, 2009, 2012, and InPage 3.x**.
- **Mixed-Language & Digit Preservation:** Keeps English words, URLs, and numbers properly aligned inside right-to-left Urdu paragraphs.
- **Urdu Text-to-PNG Transparent Image Generator:** Type Urdu in crisp **Noto Nastaliq Urdu** font and export high-resolution transparent PNG graphics for **Canva, CapCut, Adobe Photoshop, and YouTube thumbnails**.
- **Broken Urdu Fixer for Photoshop & Premiere:** Reshapes and reverses disconnected Urdu letters (`ا ر د و`) so they paste cleanly into older Adobe apps.
- **Urdu Shayari & Quote Card Maker:** Create ready-to-share Instagram and WhatsApp poetry/quote graphics with custom themes and author attribution.
- **Urdu Text Cleaner & Numeral Converter:** Strip extra spaces, normalize Arabic/Urdu characters, and convert English digits (`123`) to Urdu digits (`۱۲۳`).
- **100% Client-Side & Privacy-First:** Runs completely inside your web browser—no text is ever uploaded to or stored on any server.

---

## 🚀 How to Use (Unicode → InPage Clipboard)

1. Open [https://urdu-converter.pages.dev/](https://urdu-converter.pages.dev/).
2. Ensure your Windows taskbar keyboard language is set to **`ENG`**.
3. Paste your Unicode Urdu text into the input box.
4. Click **Copy Text** and paste (`Ctrl + V`) directly into your InPage document.
